# Write Cut

[![Проверка](https://github.com/ivanoskov/write-cut/actions/workflows/validate.yml/badge.svg)](https://github.com/ivanoskov/write-cut/actions/workflows/validate.yml)
[![skills.sh](https://skills.sh/b/ivanoskov/write-cut)](https://skills.sh/ivanoskov/write-cut)

Редакторский метод книги Максима Ильяхова и Людмилы Сарычевой «Пиши, сокращай» в формате skill для AI-агента.

Skill не полирует слабый текст. Он заново ставит задачу, проверяет правду, перестраивает логику, выводит пользу вперед и заменяет обещания фактами. Если фактов нет, не выдумывает их.

## Установка

### Универсальный способ

Для Codex, Claude Code и других совместимых агентов:

```bash
npx skills add ivanoskov/write-cut
```

Глобально, для всех проектов и поддерживаемых агентов:

```bash
npx skills add ivanoskov/write-cut -g
```

### Claude Code Plugin

Сначала добавьте репозиторий как marketplace, затем установите plugin:

```bash
claude plugin marketplace add ivanoskov/write-cut
claude plugin install write-cut@write-cut
```

В открытой сессии Claude Code те же команды начинаются с `/plugin`. После установки выполните `/reload-plugins`. В plugin-версии явный вызов получает namespace: `/write-cut:write-cut`. Автоматический вызов по смыслу запроса продолжает работать.

### Попросить AI-агента установить skill

Отправьте агенту этот промпт:

```text
Установи agent skill write-cut из репозитория https://github.com/ivanoskov/write-cut
```

## Использование

Skill включается автоматически по запросам на редактуру русского текста. Его можно вызвать явно:

```text
$write-cut

[текст]
```

Подойдут и обычные запросы: «сократи без потери смысла», «перепиши жестче», «убери канцелярит», «разбери этот текст».

## Как работает

1. Определяет читателя и переход из точки А в точку Б.
2. Проверяет правду, пользу, доказательства и ограничения.
3. Пересобирает смысл, модули, абзацы и заголовок.
4. Убирает воду, штампы, канцелярит и мертвый синтаксис.
5. Применяет отдельные протоколы к продуктам, обучению, текстам о компании и сопроводительным письмам.
6. Проверяет чистовик двенадцатью приемочными тестами.

Главное правило: безжалостно к тексту, бережно к фактам и автору.

## Источник и статус проекта

Это «Пиши, сокращай» в форме инструкций для AI-агента: сжатая операционная версия редакторского метода книги, а не ее полный текст и не замена чтению.

Авторы книги — Максим Ильяхов и Людмила Сарычева. `write-cut` — независимый проект; авторы книги и издательство с ним не связаны.
